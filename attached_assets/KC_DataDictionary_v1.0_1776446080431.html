Data Dictionary

All fields · Subfields · Sub-subfields · Tier · Version · Field type
Living document — updated every time a new field is added to the app
Version 1.0 · April 2026
Purpose: This Data Dictionary is the authoritative record of every data field KasiaCare collects, stores, or displays. It serves as the developer specification for what to build, an audit reference for data compliance, and an ongoing registry so that any new field added to the app is documented here first. Fields are organized by module. Each entry shows the field name, any subfields, sub-subfields, the tier it belongs to, the product version it appears in, and the field type.

Tier Key: All Tiers   Basic   Plus   A La Carte   Future    Version Key: V1   V2   V3+
⚠ PHI Notice: Version 1 does not store Personal Health Information (PHI). Fields marked V2 or V3+ require HIPAA review and legal counsel before development begins. No medication names, diagnoses, vital signs, or clinical data are stored in Version 1.
